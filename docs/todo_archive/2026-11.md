- [x] TODO-5639: A binding whose declared type is an imported short name skipped the Copy helper
  - owner: ai
  - status: done
  - created_at: 2026-11-02
  - phase: Strings and slices (docs/spec/strings-and-views.md), found by the TODO-5628 suite
  - parallel_track: lifecycle-strings
  - scope: `[String mut] s{stringFrom("hello")}` then `[String mut] c{s}` shared one heap block: `c.append("!!")` grew the text in place while `s.count()` stayed 5, and at scope end the VM stopped with `string heap block freed twice` (size 1 to 31) or `invalid string heap free address` (32 and up); `optexe` aborted the same way. Spelling the type `/std/text/String` worked, and so did a user struct with `Copy`. Cause: the struct-binding branch of the lowerer (`IrLowererLowerStatementsBindingsContinued.h`) resolved the slot layout from `info.structTypeName` (the full path) but looked up the `Copy` helper, and the disarm of a temporary source, with the raw type-transform name `structTypeName` (`String`, the imported short name), so `defMap.find("String/Copy")` missed and the struct was only bit-copied. Fix: use `info.structTypeName` for those three lookups. Tests: bindings of every spelling copy and free once; a copy in a 300-iteration loop; the TODO-5628 suite now uses the binding form.
  - acceptance:
    - the repro programs copy instead of aliasing (counts differ after appending to one side) and never fault; `Copy` also runs for a user struct; the TODO-5628 conformance suite uses `[String] copy{s}`; full release gate green
  - stop_rule: the three lookups in the struct-binding branch; no new move/use-after-move checking.
  - finished_at: 2026-11-02
  - result: Fixed in IrLowererLowerStatementsBindingsContinued.h: the struct-binding branch used the raw type-transform name (the imported short name String) for the Copy helper lookup and the temporary-source disarm while the layout used the resolved path, so a binding from a binding only bit-copied and the block was freed twice. Three lookups now use info.structTypeName. New tests: bindings of every spelling copy and free once; a 300-iteration copy loop; the conformance suite uses the binding form.
