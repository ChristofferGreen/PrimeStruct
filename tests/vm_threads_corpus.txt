# The concurrent corpus (TODO-5900; docs/MultithreadingPrototype.md, VM Threads).
#
# Every test source that runs a program on a task schedule is listed here. A program in the corpus runs on the eager
# schedule once and under `primevm --vm-threads` repeatedly (PRIMESTRUCT_VM_THREADS_CORPUS=<n>), and each threads run
# must print and exit as the eager run did. A program whose output depends on the interleaving is made
# schedule-independent or removed; none is accepted as flaky (AGENTS.md, No flaky tests).
#
# CMake turns the `matrix` and `cases` lines into the PrimeStruct_vm_threads_corpus_* ctest entries;
# scripts/tsan_vm_check.sh runs the same lines with a ThreadSanitizer build of primevm; and
# scripts/check_vm_threads_corpus.py (ctest PrimeStruct_vm_threads_corpus_registration) fails when a test source that
# names a task schedule (--vm-schedule-seed, --vm-threads, vmThreadsConfig, vmTaskScheduleFlags) is not listed.
#
#   matrix|<doctest suite>|<source file>|<n>         program-matrix suite in corpus mode, <n> threads runs per ctest entry
#   cases|<doctest suite>|<source file>|<case name>  doctest case run in corpus mode
#   repeated|<doctest suite>|<source file>           already repeats under threads in its own ctest entry
#   exclude|<source file>|<reason>                   names a marker but runs no concurrent program
